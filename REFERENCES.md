# References and attribution

## Architectural starting point

1. Linkhoge, **rumour-sim** (source project used as an architectural reference for modular agents, discrete simulation steps, seeded experiments, state tracking, and live visualisation).  
   https://github.com/Linkhoge/rumour-sim

2. Le Nguyen, **Simulation 102: Agent-Based Disease Modeling** (2023).  
   https://medium.com/@ln8378/simulation-102-agent-based-disease-modeling-17307f2de2f3

The current project reuses general agent-based modelling concepts, not disease-specific state transitions or rumour-spreading rules.

## Further reading

3. Epstein, J. M. (2002). **Modeling civil violence: An agent-based computational approach.** *Proceedings of the National Academy of Sciences*, 99(suppl. 3), 7243–7250.  
   https://doi.org/10.1073/pnas.092080199

4. Wilensky, U. and Rand, W. (2015). **An Introduction to Agent-Based Modeling: Modeling Natural, Social, and Engineered Complex Systems with NetLogo.** MIT Press.  
   https://mitpress.mit.edu/9780262731898/an-introduction-to-agent-based-modeling/

5. Python documentation, **random — Generate pseudo-random numbers**.  
   https://docs.python.org/3/library/random.html

## Scope note

These sources provide background on agent-based modelling and reproducible computation. They do not validate the illustrative combat parameters or imply that this toy model predicts real conflict outcomes.
